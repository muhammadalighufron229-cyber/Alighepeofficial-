# @lighepeofficial — Website pribadi

Website statis responsif untuk personal branding, profil bisnis, dan portofolio. Tidak membutuhkan database atau server backend untuk versi awal.

## Isi folder
- `index.html` — konten, metadata SEO dasar, navigasi, bagian profil/proyek/bisnis/kontak.
- `styles.css` — desain Midnight Blue responsif.
- `script.js` — menu mobile dan tahun otomatis.
- `robots.txt` dan `sitemap.xml` — contoh dasar untuk mesin pencari.
- `assets/` — favicon dan gambar sosial.

## Sebelum dipublikasikan
1. Buka `index.html` dan cari komentar `Ganti` / `sesuaikan`.
2. Profil sosial yang dimasukkan: Instagram `@guwepehasli` dan TikTok `@Al1gp`. Pastikan URL profil sudah benar sebelum publikasi.
3. Tautan WhatsApp masih berupa placeholder `https://wa.me/62XXXXXXXXXX`. Demi privasi, jangan publikasikan nomor pribadi secara terbuka; pertimbangkan nomor bisnis khusus dan minta persetujuan wali/orang tua sebelum menampilkannya.
4. Ganti `hello@example.com` ke email kontak yang memang ingin dipublikasikan.
5. Ganti kartu proyek konsep dengan proyek nyata atau hapus kartu yang belum relevan.
6. Pilih domain yang tersedia, misalnya `lighepeofficial.com` (ketersediaannya belum diperiksa).
7. Setelah domain ditentukan, ganti `YOUR-DOMAIN.example` di `robots.txt` dan `sitemap.xml` dengan domain kamu. Pastikan alamat final memakai HTTPS dan konsisten dengan pengaturan hosting.
8. Ganti URL gambar Open Graph jika kamu membuat gambar preview khusus.

## Cara termudah menerbitkan dengan GitHub Pages (hosting statis gratis)
1. Buat akun GitHub jika belum punya.
2. Buat repository baru, misalnya `lighepeofficial-site`.
3. Unggah semua file dan folder di paket ini ke root repository.
4. Di repository, buka **Settings → Pages** lalu pilih sumber publikasi dari branch utama (`main`) dan folder root.
5. Tunggu sampai GitHub Pages memberikan alamat publik. Uji lewat HP dan mode privat.
6. Untuk domain sendiri, beli domain dari registrar tepercaya. Di pengaturan Pages, masukkan domain kustom; ikuti instruksi DNS yang ditampilkan GitHub untuk menambahkan record DNS yang sesuai. Aktifkan HTTPS setelah DNS terverifikasi.
7. Setelah domain aktif, perbarui `robots.txt` dan `sitemap.xml` dengan domain final.

Nama menu layanan dapat berubah; ikuti dokumentasi resmi penyedia hosting/registrar yang kamu pilih.

## Domain, hosting, dan biaya
- **Hosting statis**: GitHub Pages dapat menjadi pilihan gratis untuk website statis seperti ini, dengan ketentuan layanan yang berlaku.
- **Domain sendiri**: biasanya berbayar dan diperpanjang berkala (umumnya tahunan). Harga tergantung ekstensi (.com, .id, dll.) dan registrar; cek harga renewal, bukan hanya harga promo.
- **HTTPS/SSL**: umumnya tersedia tanpa biaya tambahan pada hosting statis yang mendukungnya.
- **Email domain**: tidak otomatis disediakan oleh pembelian domain; layanan email dapat berbiaya terpisah.
- Domain belum dibeli atau dihubungkan dari paket ini. Website belum otomatis online hanya karena file dibuat.

## Agar bisa ditemukan di Google
1. Hubungkan domain dan pastikan website dapat dibuka publik lewat HTTPS.
2. Buat properti domain di Google Search Console dan verifikasi kepemilikan.
3. Kirim `https://DOMAIN-KAMU/sitemap.xml`.
4. Gunakan URL Inspection untuk meminta pengindeksan halaman utama.
5. Pastikan konten unik, judul/deskripsi sesuai, dan tautan sosial benar.

Pengindeksan bukan instan dan tidak dijamin. Nama akun yang unik, konten bermanfaat, tautan yang benar, serta konsistensi brand membantu orang menemukan website.

## Privasi
Website ini tidak memasang analitik, cookie pelacakan, formulir pengumpulan data, atau database. Tautan sosial membuka layanan pihak ketiga. Jangan mempublikasikan alamat rumah, nomor pribadi, atau informasi sensitif. Gunakan email bisnis khusus jika memungkinkan.
